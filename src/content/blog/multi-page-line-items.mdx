## What changed

Long invoices often split their line-item table across pages, repeating the header on each one. Inkwise now joins those tables into a single list, drops repeated headers and carries subtotals through correctly.

## How to turn it on

It is on by default for all invoice workflows. Existing documents can be reprocessed from the document view if you need the merged lines for past periods.
